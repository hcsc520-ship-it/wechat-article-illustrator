# 微信公众号文章插图（WeChat Article Illustrator）

一套用于微信公众号正文配图的 Codex Skill。它会分析文章结构与论证逻辑，找出真正需要视觉辅助的位置，并以统一的 Type × Style × Palette 方法生成可直接使用的正文插图。

## 核心能力

- 分析技术、教程、方法论和叙事类中文文章
- 判断插图能否提升理解，而不是机械地为每个段落配图
- 规划信息图、场景图、流程图、对比图、框架图和时间线
- 统一整篇文章的绘制风格、色彩与信息密度
- 为每张图片保存完整提示词，便于复现、修改或切换生图后端
- 支持参考图、批量生成、失败重试和 Markdown 图片引用

## 工作流程

```text
读取偏好与参考素材
        ↓
分析文章结构和核心观点
        ↓
确认图片类型、密度、风格与配色
        ↓
生成插图规划和独立提示词文件
        ↓
批量生成图片并写回文章引用
```

## 使用方法

在支持 Skills 的 Codex 环境中安装本目录，并使用类似指令：

```text
使用 $wechat-article-illustrator，为这篇微信公众号文章规划并生成正文插图。
```

首次使用时会创建个人偏好配置；正式生成图片前会要求确认插图方案，除非当次任务明确要求跳过确认。

## 输出结构

```text
<output-dir>/
├── outline.md
├── prompts/
│   └── NN-<type>-<slug>.md
└── NN-<type>-<slug>.png
```

每张图的最终提示词都会先保存为独立文件，再交给可用的位图生成后端，保证过程可追溯、可复现。

## 使用边界

- 主要处理微信公众号正文插图，不默认设计文章封面。
- 不负责登录、修改或发布微信公众号文章。
- 不使用 SVG、HTML 或程序化绘图冒充位图生成结果。
- 图片中的文字有误时应重新生成，不能通过覆盖像素的方式修补。
